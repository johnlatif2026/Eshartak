## 📖 عن المشروع

**إشارتك (Eshartak)** هو مشروع يهدف إلى توثيق وشرح إشارات اليد التي يستخدمها سائقو الميكروباص وموظفو المحطات في مصر لتحديد الوجهات. يقدم المشروع دليلاً مرئياً يسهل على الركاب فهم هذه الإشارات والتعامل معها.

المشروع يتكون من:
- **موقع إلكتروني عام** (Frontend) لعرض الإشارات والبحث فيها.
- **لوحة تحكم إدارية** (Admin Dashboard) لإدارة المحتوى.
- **واجهة برمجة تطبيقات (API)** للتواصل بين الواجهات وقاعدة البيانات.
- **تطبيق Flutter** (قيد التطوير) للهواتف المحمولة.

## ✨ الميزات

### 👥 للمستخدمين (الموقع العام)
- 🔍 **بحث متقدم** في الإشارات (بالوجهة والمحافظة).
- 📍 **تصفية حسب المحافظة** (القاهرة، الإسكندرية، وغيرها).
- 🎥 **مشاهدة فيديوهات** توضيحية للإشارات.
- 📤 **إرسال إشارات جديدة** (مقترحات من المستخدمين) مع رفع فيديو.
- 🌙 **دعم الوضع الداكن** (Dark Mode).
- 📱 **تصميم متجاوب** يعمل على جميع الأجهزة.

### 👨‍💼 للمديرين (لوحة التحكم)
- 🔐 **نظام مصادقة آمن** (JWT).
- 📋 **مراجعة طلبات الإشارات** (قبول/رفض).
- ✏️ **إدارة الإشارات** (إضافة، تعديل، حذف).
- 🎬 **رفع إشارات رسمية** مع فيديو ووصف.
- 📊 **إحصائيات** عن عدد الإشارات والطلبات.

## 🛠️ التقنيات المستخدمة

### الواجهة الخلفية (Backend)
| التقنية | الاستخدام |
|----------|-----------|
| **Node.js** | بيئة تشغيل JavaScript |
| **Express.js** | إطار عمل لبناء الـ API |
| **JSON Web Token (JWT)** | المصادقة وإدارة الجلسات |
| **Firebase Firestore** | قاعدة البيانات الرئيسية |
| **Cloudinary** | تخزين الفيديوهات وتحويلها |
| **Multer** | رفع الملفات |
| **Helmet.js** | حماية الرؤوس (Headers) |
| **express-rate-limit** | منع هجمات الـ DOS |

### الواجهة الأمامية (Frontend)
| التقنية | الاستخدام |
|----------|-----------|
| **HTML5** | هيكل الصفحات |
| **CSS3** | التصميم والتنسيق |
| **JavaScript (Vanilla)** | التفاعلات والـ API calls |

### النشر والاستضافة
| التقنية | الاستخدام |
|----------|-----------|
| **Vercel** | استضافة الموقع والـ API |
| **Firebase** | قاعدة البيانات والتخزين |
| **Cloudinary** | تخزين الفيديوهات |
